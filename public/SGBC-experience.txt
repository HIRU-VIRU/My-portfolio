* Designed and implemented a fully asynchronous ML training execution pipeline using Celery workers.
* Decoupled long-running model training from synchronous API requests to prevent backend blocking.
* Built job submission APIs that immediately return job identifiers while background workers execute training tasks.
* Implemented centralized job lifecycle management (Queued → Running → Completed → Failed).
* Developed APIs for querying training status, metadata, execution logs, and results.
* Standardized asynchronous response formats across all training workflows.
* Improved backend responsiveness under concurrent training workloads.
